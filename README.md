# DIZEUR Android

Assistant vocal Android pour contrôler Deezer.

Le projet source complet est fourni dans `DizeurAndroid-alpha-1.1.zip`. Le workflow GitHub Actions extrait cette archive, compile l'application Android et publie l'APK debug comme artefact lorsque la compilation réussit.

Version source : 1.1-alpha.

> Cette version doit encore être compilée et testée sur un appareil Android. La présence du code dans ce dépôt ne signifie pas que l'application a déjà passé ces tests.
